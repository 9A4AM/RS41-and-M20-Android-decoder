# RS41-and-M20-Android-decoder
RS41 and M20 Android decoder in pure B4A. 
Only need preinstalled RTL_SDR (SDR Driver -> Signalware Ltd). 
Phone with OTG and RTL_SDR(tested with V3 and V4). 
After starting App decoder automaticly detected type RS41 or M20. 
With Button Geo App open Geo Aplication and transfer coordinate from decoder and make marker with Payload ID on map. Last packet stored. Long press Stop button open Last received telemetry.
Source code publish after cleanup. APK in Release. Language English or Croatian.
